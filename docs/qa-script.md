# haochen QA 人肉模拟脚本（用户视角操作单）

> 用途：给「分屏独立 QA agent」的操作说明（总纲 §四.3 / product-acceptance §四.3）。只给操作，不给实现细节；QA 汇报格式：操作 → 预期 → 实际现象 → 判定。
> 目标 App：`packaging/dist/haochen.app`（ad-hoc 签名，本机可直接双击；异机需先 `xattr -d com.apple.quarantine`）。数据目录默认 `~/Library/Application Support/haochen/`。

---

## 前置

申请做以下准备（由研发/产品协助）：
- 若首次运行，授权引导卡片出现：按卡片指引去 系统设置 → 隐私与安全性 → 辅助功能 打开 haochen。

## 用户视角操作序列

### A. 启动与权限
1. 双击 `haochen.app`（或在 Finder 双击）。
   - 预期：右下角出现像素眼镜小哥；Dock 无图标；无崩溃弹窗。
2. 首次运行：出现「授权辅助功能」引导卡片。
   - 预期：卡片文字说明 + 三个按钮（去授权 / 我已授权 / 暂不）。
   - 操作 2a：点「去授权」→ 系统设置自动打开到辅助功能面板。
   - 操作 2b：在系统设置辅助功能列表打开 haochen 开关。
   - 操作 2c：回到 haochen 点「我已授权」→ 卡片消失，授权成功。

### B. 对话（完整窗口）
3. 双击桌宠 → 气泡出现；点气泡里「展开」或在菜单打开完整对话窗口。
   - 预期：气泡从桌宠方向淡入上滑；窗口左侧会话列表、右侧对话流。
4. 输入框输入「用一句话介绍你自己」，回车。
   - 预期：用户气泡居右；haochen「思考」状态条；随后「结论」短结卡片 + 详答；流式输出；Markdown 正确（加粗/代码块）。
5. 问「看看我屏幕上是什么」：
   - 预期：出现「我正看一下你的屏幕…」感知提示 + 读屏确认条「读吧/不读」；点「读吧」→ 工具卡（read_screen）→ 答出当前窗口内容。

### C. 会话
6. 点左侧「+ 新会话」，问一个新问题。
   - 预期：新会话；原会话仍在列表。
7. 切回原会话 → 历史还在。
8. 右键会话 → 重命名 / 删除。
   - 预期：改名生效；删除后列表移除，重启 App 后历史不回滚（删除的除外）。
9. 关闭 App 再打开：历史会话仍在。

### D. 桌宠
10. 双击桌宠 / `⌃⌥P`（如果授权成功）：气泡唤起。
   - 预期：气泡在桌宠上方，右下尾巴对准桌宠。
11. 问到一半按 Esc：打断。
   - 预期：状态条「已停止（保留已产内容）」；不卡死。
12. 点气泡外空白 / 右上 ✕：收起。
   - 预期：气泡淡出；桌宠回 idle。
13. 失焦（切到别的 App）：气泡**不**自动收起；idle 时桌宠安静不打扰。

### E. 配置
14. 桌宠右键 → 设置：打开设置面板。
   - 预期：模型 / API Key / 默认思考档 / 主题 有 UI；米白主题。
15. 改默认思考档 → 立即保存。
   - 预期：状态条「已保存 · 立即生效」。
16. 换 deepseek 不同模型（如 flash pro 切换）→ 立即生效（无需重启）。
17. 切换 provider 时提示重启引擎 → 确认后重启 → 生效。

### F. 健壮性
18. 打开「活动监视器」，找到引擎进程（haochen-engine），强制退出。
   - 预期：App 显示「引擎已退出，自动重启中」横幅；约 1 秒自动恢复；追问上下文不丢。
19. 断网后问一句。
   - 预期：错误条「可重试」；不白屏、不崩溃。
20. 连续快速问 10 轮。
   - 预期：稳定完成；无卡死、无内存爆炸（肉眼）。

### G. 收尾
21. 右键桌宠 → 退出。
   - 预期：桌宠 + 引擎进程全部退出；无残留。
