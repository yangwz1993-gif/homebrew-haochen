# haochen v0.1.6 修复验收点

> 依据：用户真机验证 v0.1.5 后反馈的 3 个问题。给 kimi 实现（resume v0.1.5 会话）。

## 1）读屏确认按钮：浅白看不清 → 改回醒目绿色
- **问题**：读屏确认弹窗里的「读吧」按钮变成**浅白色，看不清**。
- **要做**：「读吧」（允许）改为**醒目绿色**（品牌绿，如 `#2e8b57`/`#3a7d44`，白字），高对比；「不读」（拒绝）保持次要/中性。上一版绿色样式恢复，勿用浅白。

## 2）小窗文本框线：去掉"大框套小框"的丑边框
- **问题**：小对话窗里每次文本都带**显眼方框**（回答/用户消息各自一个深色边框，大框套小框，很丑）。
- **要做**：去掉这些**明显边框线**，改为简洁样式：用**背景色区分**（回答淡米白卡片、用户消息浅调），**不画每个文本块的深描边**；保留极轻的分隔或直接无框，符合 visual-spec（米白底、卡片化、圆角，但不要每个文本一个深框）。

## 3）小窗与人物位置：固定在人物正上方、联动拖动
- **问题**：**小对话窗压在 haochen 形象上**（遮挡/重叠）。
- **要做**：
  - 小对话窗（气泡）**永远固定在人物（haochen 形象）正上方**（在人物头顶，有合理间隙，不压住人物）。
  - **人物和对话框联动**：拖动人物 → 对话框跟着走（保持"在头上"）；拖动对话框 → 人物跟着走（或二者作为一个整体移动）。要**能拖动人**也能**拖动对话框**，且关系始终"对话框在人物正上方"。
  - 移动后位置要**记忆/保持**（即用户摆好位置后下次仍是该位置）。
