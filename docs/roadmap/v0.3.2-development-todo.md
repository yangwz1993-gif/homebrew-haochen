# haochen v0.3.2 开发与交付清单

> 目标：完成 P0/P1/P2 后，以独立用户验收、legacy DMG、GitHub Release、Homebrew 升级和本机安装构成交付闭环。

## P0：短气泡与身份边界

- [x] 明确结果气泡自动退场为 20 秒，并在鼠标交互期间暂停、离开后继续剩余时间。
- [x] 短气泡右上角提供小型关闭图标，输入区提供发送和完整会话展开图标。
- [x] 展开完整会话时保留未发送草稿；所有图标提供悬停提示与辅助功能名称。
- [x] 桌宠唯一名字固定为小写英文 `haochen`，没有中文名；未设置用户称呼时只称“你”。
- [x] 旧版未确认称呼不再注入模型，避免把“阿晨”误认为用户姓名。

## P1：冷启动、长期档案与自定义模型

- [x] 首启向导增加可跳过、可迁移确认的用户称呼步骤。
- [x] 用户档案升级为 v2 结构，记录确认状态、来源和更新时间；设置页可修改或清除。
- [x] 首启允许选择 DeepSeek 预设或填写自定义 OpenAI 兼容模型。
- [x] 设置页允许添加、测试、编辑、删除自定义 URL、模型 ID、显示名称、协议和 Key。
- [x] 公网地址强制 HTTPS，拒绝 URL 内嵌凭据与查询参数；连接并确认模型 ID 后才保存。
- [x] Key 只进入 macOS Keychain；配置文件只保存安全引用；失败时事务回滚旧模型和旧凭据。
