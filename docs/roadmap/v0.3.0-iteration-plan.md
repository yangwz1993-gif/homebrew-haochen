# haochen v0.3.0 交付迭代计划

> 目标：交付可供普通用户安装和持续使用的 macOS App。暗色模式不作为当前前置条件。

## Iteration 1：小窗正确性与稳定骨架

- 消除输入态和结果态的非设计性大面积空白，内容变化后重新计算紧凑高度；
- 输入、处理中、授权、结果、错误使用互斥视图，失败时不得残留工作状态；
- 修复“继续问”原位恢复输入和聚焦，覆盖自动退场竞争条件；
- 保证人物始终可见，气泡尾巴稳定指向人物；
- 单击与双击均可发现核心入口，首次提供轻提示；
- 把凭据、余额、网络、权限错误转换为人话，隐藏敏感或技术细节；
- 自动化记录各状态矩形、空白和延迟，再构建隔离试用包进行独立复验。

## Iteration 2：小窗视觉重构

- 重做无标题栏的输入耳语条、轻量工作泡、明确授权卡和紧凑结果卡；
- 统一气泡轮廓、尾巴、字体、行距、按钮高度、图标与主次关系；
- 平滑内容高度变化，避免几何跳跃；
- 在不幼态化的前提下接入原成年像素工程师的关键动作；
- 覆盖短中文、长中文、英文、列表、屏幕边缘和 Reduce Motion。

## Iteration 3：回答和详情工作台

- 简答固定为直接结论、最多两个高信息量要点和可选下一步；
- 建立“说人话”真实模型评测集；
- 详情区分结论、依据、工具轨迹和产物；
- 收紧完整窗口空状态、侧栏、模型信息和输入区；
- 完成键盘、VoiceOver、连续追问和详情收回路径。

## Iteration 4：发布候选版

- 长时间、多屏、异常网络、权限恢复、崩溃恢复和升级回滚测试；
- 干净用户环境安装验收；
- Developer ID 签名、公证、DMG、Homebrew Cask 和发布说明；
- 独立用户做最终全链路验收，无阻断和明显瑕疵才允许发布。

## 每轮门禁

`实现 → make check → 真实模型/系统场景 → 构建隔离包 → 独立盲测 → 状态测量 → 用户参考差异 → 修复 → 独立复验`

Codex 剩余额度接近或低于 50% 时停止新迭代，保存代码、测试、构建证据、验收报告和
明确的下一步。额度数据不可读取时记录为未知并继续定期重试，不臆测百分比。
