# haochen v0.3.0 开发清单

> 分支：`feat/v0.3-transient-results`  
> 对应方案：`docs/roadmap/v0.3.0-experience-redesign.md`  
> 更新规则：完成项必须同时具备代码、自动化验证和必要的真实体验证据。

## P0：合并与可试用基线

- [x] 修正交互概念图最终人物肤色，保持原有成年像素工程师形象。
- [x] 临时结果卡只显示当前简答，不常驻输入框或历史流。
- [x] 增加“继续问”“查看详情”和 8 秒自动退场。
- [x] 回答协议改为一次模型调用生成 `brief + detail`。
- [x] 修复 PR #6 的 macOS CI 生命周期竞态，并确认远端检查变绿。
- [x] 生成与正式版数据、Keychain 和权限治理隔离的本地开发试用包。
- [x] 真实模型自动验收普通问答、单回合分层结果、多轮追问、读屏确认、崩溃恢复（19/19）。
- [ ] 在已授予辅助功能权限的可见开发包中，人工验收真实读屏、拒绝授权、详情展开和自动退场节奏。

## P1：漫画式状态反馈

- [ ] 将状态拆分为 listening / acknowledging / perceiving / acting / composing / presenting。
- [ ] 用真实引擎和工具事件驱动状态文案，不展示或伪造隐藏思维。
- [ ] 为原角色制作并接入倾听、观察、执行、整理、呈现、警示关键帧或 sprite。
- [ ] 增加漫画思考泡、分阶段结果入场和 Reduce Motion 静态替代。
- [ ] 工作中提供低干扰“停止”入口；授权卡始终保持明确且不自动消失。

## P1：回答与详情体验

- [ ] 将 `brief` 进一步结构化为结论、最多两个要点和可选下一步动作。
- [ ] 建立“说人话”评测集，覆盖闲聊、技术判断、读屏总结、错误恢复和信息不足。
- [ ] 详情页明确区分结论、依据、工具轨迹和产物，减少重复与大面积空白。
- [ ] 完成从结果卡展开详情、连续追问、收回桌宠的键盘与 VoiceOver 路径。

## P2：统一视觉与发布质量

- [ ] 合并 pet/chat/settings 的设计 Token，接入系统浅色与暗色模式。
- [ ] 完成 hover / pressed / focus / 高对比度状态和跨 App 点击退场策略。
- [ ] 跑长时间稳定性、多屏、性能、权限恢复与异常网络测试。
- [ ] 完成签名、公证、Homebrew Cask 审计和升级/回滚验证。
- [ ] 更新版本、CHANGELOG、发布说明并通过 PR 合并发布。

## 本地开发版

- App：`packaging/dist/haochen.app`
- DMG：`packaging/dist/haochen-0.3.0-dev.1.dmg`
- 安全启动：`scripts/launch-development-build.sh`
- 默认开发数据：`~/Library/Application Support/haochen-development`
- 默认开发 Keychain 服务：`com.haochen.app.development.api-key`

开发包使用 ad-hoc 签名，只用于本机试用，不分发。启动脚本会跳过正式版的权限指纹治理，避免清除已安装版本的系统授权。
