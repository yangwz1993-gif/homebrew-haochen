# haochen v0.3.0 开发清单

> 分支：`feat/v0.3-transient-results`  
> 对应方案：`docs/roadmap/v0.3.0-experience-redesign.md`  
> 迭代顺序：`docs/roadmap/v0.3.0-iteration-plan.md`
> 更新规则：完成项必须同时具备代码、自动化验证和必要的真实体验证据。

## P0：合并与可试用基线

- [x] 修正交互概念图最终人物肤色，保持原有成年像素工程师形象。
- [x] 临时结果卡只显示当前简答，不常驻输入框或历史流。
- [x] 增加“继续问”“查看详情”和 8 秒自动退场。
- [x] 回答协议改为一次模型调用生成 `brief + detail`。
- [x] 修复 PR #6 的 macOS CI 生命周期竞态，并确认远端检查变绿。
- [x] 生成与正式版数据、Keychain 和权限治理隔离的本地开发试用包。
- [x] 真实模型自动验收普通问答、单回合分层结果、多轮追问、读屏确认、崩溃恢复（19/19）。
- [ ] 在已授予辅助功能权限的可见开发包中，人工验收真实读屏、拒绝授权、详情展开和自动退场节奏。

## P1：漫画式状态反馈

- [x] 将状态拆分为 listening / acknowledging / perceiving / acting / composing / presenting。
- [x] 用真实引擎和工具事件驱动状态文案，不展示或伪造隐藏思维。
- [x] 重构小窗视觉：气泡轮廓、标题、留白、输入区、状态区、结果卡、尾巴与按钮层级。
- [ ] 为原角色制作并接入倾听、观察、执行、整理、呈现、警示关键帧或 sprite。
- [x] 增加漫画式阶段脉冲、分阶段结果入场和 Reduce Motion 静态替代。
- [x] 工作中提供低干扰“停止”入口；授权卡始终保持明确且不自动消失。
- [ ] 按 `docs/aesthetic-user-gate.md` 通过独立审美用户首次验收与修复后复验。

### 独立审美验收第 1 轮修复项

- [x] 失败时彻底结束工作态，以人话错误卡替代技术错误与残留“停止”。
- [x] 保证“继续问”原位恢复输入并聚焦，不出现意外收起。
- [x] 保证气泡出现时人物可见、尾巴明确指向人物且二者不脱节。
- [x] 增加单击反馈与首次轻提示，降低隐藏双击手势的发现成本。
- [x] 修正小尺寸人物硬裁切和头像感，保持原成年像素工程师形象。
- [x] 稳定输入、工作、结果三态的锚点，消除旧内容造成的异常高度和人物脱节。
- [x] 收紧输入与结果卡的非设计性留白。
- [x] 平滑状态间尺寸过渡，统一气泡、标题、按钮、图标和尾巴语言。
- [ ] 重构完整对话窗空状态、侧栏、模型信息和输入区的密度与层级。

### 独立审美验收第 2 轮

- [x] 用盲测、状态矩阵、联合截图和数值测量复核用户的小窗留白问题；确认当前输入态
  最大连续空白约 `13px`，旧截图问题未复现。
- [x] 修复“错误 → 检查设置 → 关闭设置”后错误原因与重试入口丢失。
- [x] 停止后明确进入 `CANCELLED`，标注结果只包含停止前已完成内容。
- [x] 移除处理中错误出现的“已排队”重复卡，避免状态相互矛盾。
- [x] 使用安全引用的有效 Keychain 完成真实问答六状态复验。
- [x] 在 Retina 屏按设备像素比渲染人物素材，保留原成年像素工程师风格与逻辑尺寸。

### 独立审美验收第 3 轮

- [x] 新用户首次启动时提供一次性、非打扰的“点击人物开始”提示。
- [x] 让 `ACKNOWLEDGING` 保持肉眼可辨认的最短展示时间，再进入真实工作状态。
- [x] 拒绝读屏后的首帧立即撤销“读取中 / 已允许”语义。
- [x] `CANCELLED` 丢弃完成式 brief，只说明停止前内容已保留。
- [x] 修复 mock 状态证据名与真实捕获状态不一致。
- [ ] 重构详情页重复标题、模型名断行和大面积空状态。

### 独立审美验收第 4 轮

- [x] 盲验确认旧式桌面常驻大框已消失，人物风格、Retina、气泡关系和按钮层级通过。
- [x] 修复“详情收起竞态 → 成功答案已入历史但桌面结果气泡消失”，增加 50 次短结果与
  20 次详情收起竞态回归。
- [x] 将读屏拒绝/取消显示为中性“未执行”，折叠态不再使用绿色成功对勾。
- [x] 设置页区分“Key 已存储 / 尚未验证 / 已验证 / 当前验证失败”，错误入口不再给出
  相互矛盾的绿色成功状态。
- [x] 首次点击提示延长到 8.5 秒，并补充“点击开始对话”的辅助功能名称。
- [ ] 用新隔离构建完成第 5 轮独立复验，确认上述四项且无新增阻断/明显瑕疵。

## 本地开发版

- App：`packaging/dist/haochen.app`
- DMG：`packaging/dist/haochen-0.3.0-dev.1.dmg`
- 安全启动：`scripts/launch-development-build.sh`
- 默认开发数据：`~/Library/Application Support/haochen-development`
- 默认开发 Keychain 服务：`com.haochen.app.development.api-key`

开发包使用 ad-hoc 签名，只用于本机试用，不分发。启动脚本会跳过正式版的权限指纹治理，避免清除已安装版本的系统授权。
