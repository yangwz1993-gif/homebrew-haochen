# haochen v0.1.4 体验优化（研发验收点）

> 依据：用户确认的对齐理解（0/1/2），含两处定论。给研发(kimi)实现。

## 0）初始授权流程简化
- **去掉产品自己的黄色授权引导框/卡片**——不再让用户点"去授权/我已授权"那种黄色弹窗。
- 改用 **macOS 系统授权弹窗**：app 检测到权限未授权时，**直接触发系统弹窗**（`AXIsProcessTrustedWithOptions(prompt:true)` / `CGRequestScreenCaptureAccess()`）让用户按系统流程授权。
- **保留**「重置重授」能力（针对假蓝/TCC 记录与签名 ID 不符）：检测到"系统里开关看似已开但 app 仍检测未授权(假蓝)"时，用重置重授刷新（清 TCC 记录+重弹系统授权），这是根治反复授权的。
- 授权全部完成后**提示/自动重启** app 生效（屏幕录制需重启）。
- 说明（macOS 机制）：辅助功能/屏幕录制仍需用户在系统设置里打开开关（系统弹窗会指向设置，这是系统限定，无法完全省掉手动开关，但**不再有我们的黄色卡片**）。

## 1）详情页（对话详情窗口）
- **a）"结论"(L1 短结) 移到整体回答的下面** —— 即**先显示详答(L2)，再在最下方给出"结论"**（反转此前的"结论先行"）。已与用户确认。
- **b）点「展开详细」→ 跳转/展开到详情窗口**的对应位置（详情窗口显示被点击的这条回答的完整内容）。
- **c）详情窗口交互**：
  - 支持 **⌘W 关闭**；
  - 从**短会话窗口直接做动画扩展**到详情窗口（平滑过渡）；
  - **Esc 可收起**（回到短会话）。

## 2）小窗 UI 优化
- 消息区**灰色底太丑** → 优化为清爽样式（米白/卡片化，符合 visual-spec）。
- **其它小窗**（如气泡、设置、确认条等）一并优化统一风格。
