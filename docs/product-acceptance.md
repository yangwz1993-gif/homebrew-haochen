# haochen 商业级交付验收清单（产品终审 · 可交付判定）

> 版本：v1.0 ｜ 作者：产品 ｜ 用途：作为「产品判定可交付上市」的终审标准，同时是每阶段里程碑的符合性审查依据。
> 目标：完整、开箱即用、0 bug、商业级、体验完美。以下全部满足，产品才输出「可交付」。

---

## 0. 一票否决（任一不满足直接打回）

1. **开箱即用**：在干净的 mac（或新用户账户）上装 `.dmg` → 能开 → 能引导权限 → 能完成一轮完整问答。不能有"还要手动配一堆"。
2. **0 致命 bug**：无崩溃、无白屏、无数据丢失、无"引擎起不来"、无权限授权后功能仍不可用。
3. **数据/配置隔离**：运行全程不写 `~/.pi`、不碰全局 pi 配置；数据全在 `~/Library/Application Support/haochen/`。
4. **会话不丢**：重启后历史会话仍在；气泡↔窗口同一会话、不割裂。

## 二、体验质量（商业级 · 产品终审重点）

### 视觉（visual-spec）
- 米白 `#fdf6e3` / surface `#fffaf0` / 深 `#2b2b22`；2px 描边；圆角 16/8/12；四级字体；像素小哥三姿态；双入口一致；右下尾巴。

### 交互（interaction-spec）
- **感知可见**：读屏有「我正看一下你的屏幕…」+ 姿态；工具以工具卡呈现、可展开/暂停。
- **行动可见**：每步工具调用（读屏/命令/文件）工具卡可见，可展开、可暂停。
- **结论先行**：L1 短结 + L2 详答。
- **先问再动**：读屏/权限/动用户文件前先确认。
- **随时可打断**：Esc/点空白；生成中可 stop；可继续追问。
- **连续性**：对话上下文不丢，气泡↔窗口同会话。
- **不打扰**：idle 安静；只在需要确认/出结果时轻提示。
- **动态对话流**：输入→思考→结果逐条弹出（MVP 动效），非固定输入框。

### 细节
- 权限引导步骤化、可跳过但功能需授权才可用；错误信息面向用户可理解、可重试；无闪烁/无跳跃。

## 三、健壮性（0 bug）

- 引擎崩溃/被杀 → App 感知 + 重启/明确报错，不白屏。
- 配置文件缺失 → 模板自动初始化；JSON 损坏 → 重置入口。
- 多模型切换回归；长时间运行稳定（会话堆积、内存、引擎重启恢复）。
- 工具失败路径正确（读屏拒绝、命令出错、模型 429 重试）均不崩、有提示。

---

## 四、验收流程（每里程碑）

1. **研发交付**：提交代码路径 + 截图/录屏 + 自检/自测结果 + 已知限制。
2. **产品符合性审查**：对照本清单 §0/§一（对应里程碑）+ §二（体验）。
3. **QA 人肉模拟**（沿 M0 做法）：用户视角操作 + 现象 + 截图，与预期比对。
4. **结论**：通过 / 打回（附问题清单）。打回 → 研发修 → 复审。

---

## 五、可交付判定（产品输出）

**全部满足** §0（无一票否决）+ §一（6 条全过）+ §二（体验达标）+ §三（0 bug）+ 最小完整回归（§四）→ 产品判定**可交付上市**，置位 `DONE_MARKER`，dev-loop 保活值守退出。
