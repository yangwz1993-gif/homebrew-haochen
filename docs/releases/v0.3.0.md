# haochen 0.3.0

这一版把 haochen 从“桌面上的聊天窗口”升级成更像真实伙伴的像素桌宠：提问时用漫画式
气泡展示正在倾听、观察、执行和整理，完成后只留下简明结论，需要时再展开完整详情。

## 主要变化

- 桌面结果不再常驻大对话框，提供“继续问”“查看详情”和自动退场。
- 一次回答同时生成简明结论与完整详情，结论更直接，减少客服腔和过程复述。
- 首次提示、人物单击与右键入口更容易发现，右键可进入完整对话、设置和新会话。
- 完整会话按顶部阅读顺序展示短对话，历史在冷启动后恢复。
- 改进读屏确认、拒绝反馈、停止任务、错误恢复、Markdown、设置状态和键盘操作。
- 保留原有成年像素工程师形象与肤色，优化 Retina 清晰度、人物裁切和气泡锚点。

## 安装

推荐使用 Homebrew：

```bash
brew tap yangwz1993-gif/haochen
brew install --cask haochen
open -a haochen
```

首次启动按向导配置模型 API Key。Key 存储在 macOS Keychain；读屏和看图能力只在需要时
请求辅助功能与屏幕录制权限。

## 分发说明

0.3.0 延续上一版的 legacy Homebrew 分发方式：App 使用发布者稳定自签身份
`haochen Local Signing`，没有经过 Apple Developer ID 签名或 Apple 公证。Homebrew Cask
安装后会移除 App 的 quarantine 属性；直接下载并双击 DMG 可能被 Gatekeeper 拦截。
