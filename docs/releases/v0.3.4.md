# haochen v0.3.4 — 桌面阅读与交互里程碑

2026-09-11，所有者完成 rc.8 实际使用验收，并明确批准同步 GitHub 与 Homebrew。正式版不扩展功能，仅更新版本及发布元数据。

## 这版带来什么

- 更轻的中性气泡、统一的完整会话与设置界面，修正留白、输入框、窗口标题栏和人物定位。
- 从首次填写模型到第一句聊天走完整就绪流程，预设与自定义服务一致；必要的钥匙串授权由用户明确操作触发。
- 提问时识别当前页面，不默认继续读上一页；固定窗口/页面/文档对象，真实文字与原图优先，截图仅辅助。
- 阅读状态明确：正在固定时请暂勿切换，固定后可以切换，内容和本轮图像获取处理结束才显示“已读取”。
- 提速不靠少读：读取进程复用、免重复解包、同轮重复图片 URL 合并下载，保留既有采集量和质量规则。

## 验证与边界

471 项自动化测试、83% 覆盖率；复杂 BBC 文章连续读取、同标签换页、绑定后切走、取消与恢复及真实引擎进度事件均已验证。测试页固定画面约 0.24 秒，完整获取约 2.4～4 秒，网络/页面/系统状态会影响耗时；这不是整轮模型回答时间。

固定前切走时，原页面正文及 URL 原图仍可能读取，但不会误用新标签截图补旧内容；并非所有第三方 App 都支持后台完整读取。更多证据见 [rc.8 验证记录](../reviews/v0.3.4-rc.8-reading-latency.md)。

## 安装或升级

```bash
brew tap yangwz1993-gif/haochen
brew install --cask haochen
```

已通过 Homebrew 安装：

```bash
brew update
brew upgrade --cask haochen
```

若是手动拖装的候选版，请退出旧 App，再用正式 DMG 替换 `/Applications/haochen.app`；不要同时运行两个副本。无需清空配置、聊天记录或系统权限。升级后若钥匙串要求许可，请通过 App 的连接流程明确授权，不要重置整套钥匙串。

## 分发方式与回滚

沿用 legacy DMG + Homebrew Cask：发布者稳定自签名，未经 Apple Developer ID 签名或 Apple 公证；Cask 安装后移除 App 的 quarantine 属性。辅助功能与屏幕录制权限仍由用户按需授予。当前安装包为 Apple Silicon 构建，不宣称已验证 Intel 原生兼容。

如需回滚，退出 App，从上一版 GitHub Release 获取 v0.3.3 安装包并替换应用，保留 `~/Library/Application Support/haochen` 与钥匙串。不要执行 `brew uninstall --zap`。历史 Release 与标签不覆盖、不删除。
