# haochen 0.3.1

这是一个桌宠输入气泡的体验修复版本。它解决输入框越过气泡外框的问题，并让提问入口更像人物自然说话时出现的轻量漫画气泡，而不是常驻工具条。

## 主要变化

- 输入区严格收在气泡主体内，普通位置和屏幕顶部翻转时都保留稳定留白。
- 一至三行输入随内容自然增高，第四行起只在输入区内部滚动，不再挤压气泡边界。
- 缩短气泡宽度，减小发送按钮，移除输入框的第二层圆角外框。
- 占位文案只保留“问我点什么…”，键盘说明改由无障碍描述和悬停提示承载。
- 修复首次问候与输入框并存时的大片空白，让第一眼状态也保持紧凑。
- 待机、思考和警示状态采用全身动作，保持 v0.3.0 的成年像素人物特征与暖橙肤色，不走卡哇伊化路线。
- 姿态切换改为接近不透明的轻过渡，彩色桌面不再透过人物造成瞬时肤色漂移。
- 修复延迟滚动回调可能晚于窗口销毁、引发 Qt 原生段错误的问题。

## 安装

推荐使用 Homebrew：

```bash
brew tap yangwz1993-gif/haochen
brew install --cask haochen
open -a haochen
```

已安装旧版时运行：

```bash
brew upgrade --cask haochen
```
