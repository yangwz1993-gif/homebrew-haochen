# haochen 0.5.0-beta.1 · 本机验收说明

这是独立功能分支上的本地预览，不是已发布的稳定版。沿用 legacy DMG 分发路线；当前不更新 GitHub Release 或 Homebrew。没有清空旧版本配置、日志、Keychain 或系统授权。

本次本机构建为 Apple Silicon（arm64），在本机 macOS 26.6.2 验证；尚未验证 Intel Mac 和其他 macOS 版本。使用稳定自签身份，未经 Apple 公证。

## 先从这里开始

1. 退出正在运行的旧 haochen，避免两个人物同时出现；不要删除数据目录。
2. 打开本次 DMG，将 haochen 拖入「应用程序」替换旧 App，然后从应用程序启动。
3. 已使用过的用户沿用原模型与个人资料；新用户先完成原有首启向导。
4. 总览可从右侧小入口、桌宠右键「打开桌面总览」、应用菜单「桌面总览」打开。应用内 `⌘2` 打开总览，原全局 `⌃⌥P` 仍唤起桌宠气泡。

## 建议验收顺序

### 总览与操作

- 点击应用动态、事项、今日日报：均为当前总览上的浮窗，不跳整页。
- `Esc`、右上角关闭、浮窗外点击：逐层返回；输入法候选阶段不能把浮窗误关。
- 添加事项输入到一半关闭，再次打开：草稿保留；已保存内容重启后仍在。
- 「连接与外观」中对比浅雾绿、暖白石墨、冷白雾蓝、中性炭灰；选择减少动态效果或顶部/侧边入口。
- 点击「问 haochen」后，上下文进入原桌宠输入框，已有草稿不丢失，必须由你确认发送。

### Otty

打开 Otty 后自动展示实际 Agent 元数据。点击来源跳回真实 pane，目标不存在时明确失败。

若能看到 Agent 但状态为「未知」，请在 **Otty 设置 → Agents** 安装该 Agent 的官方集成，然后重启相应 Agent 会话。haochen 不会私自改全局 Agent 配置，也不会把空状态猜成已完成。`idle` 仅表示一轮结束/空闲，不表示用户事项已经完成。

### Chrome

1. 在总览「连接与外观 → Chrome」打开扩展文件夹。
2. 打开 Chrome 的「管理扩展程序」，开启开发者模式，加载上述文件夹中的解压扩展。
3. 复制 Chrome 显示的扩展 ID，回到 haochen 输入并安装本机桥接。
4. 打开想追踪的网站，点击 haochen 扩展，主动授予该站点权限并选择追踪此页。

本版不会自动读取所有标签页。追踪页面有真实 DOM 变化时才形成内容变化；原标签页导航到另一个网址、关闭、休眠或撤权都会明确显示，不擅自改读新页面。读取范围是主框架文字，不含输入框、图片、未加载内容或跨域框架；超出采集上限会标注范围。

「打开来源」会通过当前浏览器配置的本机桥接，复验网址和标签身份后定位原标签；必须收到 Chrome 确认才算成功，失效时不擅自另开网页。

扩展是本地解压安装版本，尚未提交 Chrome 商店。移动/重装 App 或扩展 ID 改变后，需要重新安装桥接。移除方法见扩展附带的 README。

### 日历

点击「连接日历」才申请系统权限。系统授权称为完整日历访问，但产品只读，不创建或修改事件。可选择已同步到 macOS 的具体日历，显示未来 7 天日程；空日历、未同步账户与未授权不是同一种状态。

### 文件与事项

- 拖入或点击选择具体工作文件夹/文件。文件条只保存入口；移除入口不删除原文件。
- 新建事项填写名称、关注目标、多条渠道和频率。文件渠道只能选已添加入口；应用渠道只能选已取得的事件；网页渠道必须已在 Chrome 扩展中授权追踪。
- 文件读取不递归整个目录：目录只检查直接子项元数据；支持范围内的 UTF-8 文本读取正文，其他格式/过大文件明确标注只读元数据。
- 默认仅本机检查。勾选「允许 AI 整理」才把选中渠道的已读取内容发往你配置的模型，可能产生模型费用。后台摘要无工具、无项目提示文件，也不占用或改写当前聊天会话。
- 暂停、修改、取消和关闭连接时，旧的在途结果不能覆盖新状态；AI 不会擅自把事项标为完成。

### 日报与信息边界

日报只总结 haochen 运行时、已连接来源的真实变化和事项检查，不代表所有 App 的全天记录。未观测时段不会补造历史。

证据面板保存可追溯的摘录与来源/检查时间，不是完整文档归档；长内容会标注预览截断。生成历史最多 31 天、1500 条变化快照，总缓存上限 32 MB，达到上限会清理较早的生成记录，不删除事项定义或原文件。

飞书按本轮决定延期。个人微信没有可靠公开后台消息接口，本版明确显示受限，不读取私人数据库，不伪造已连接或未读数字。

## 不在本轮自动执行

- 不安装 Otty hooks、Chrome 扩展或替用户授予日历权限。
- 不发布线上版本，不替换现有 Homebrew 配方。
- 不清空用户历史数据，不创建旧 App 的额外可启动备份。
