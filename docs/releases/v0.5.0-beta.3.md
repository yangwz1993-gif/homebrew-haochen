## 安装通道

- 独立 Cask：`yangwz1993-gif/haochen/haochen@beta`，仅 Apple Silicon。
- 所有者确认保留 GitHub 普通 Release 标记；版本仍为 `0.5.0-beta.3`，并只通过独立 Beta Cask 分发。默认 `haochen` Cask 当前仍是历史 `0.3.3`，不应误称已经同步 `0.3.4`。
- 两个通道都安装 `haochen.app`、共用数据，不能同时安装。已装稳定 Cask 的用户先正常退出 App、执行 `brew uninstall --cask haochen`（不要 `--zap`），再选择 Beta。

```bash
brew tap yangwz1993-gif/haochen
brew update
brew install --cask yangwz1993-gif/haochen/haochen@beta
```

本机已手动安装相同 beta.3 的用户无需重装。不要为接手调试重复卸载、删除钥匙串或清空权限。

## 可用内容与已知问题

桌面总览、刘海/桌宠入口、文件条、事项及日报浮窗已实现。Chrome 实际网页读取、正文变化、原标签跳转与首次站点授权已验证；扩展尚未上架，需要从 App 附带目录加载并逐页选择。

Otty 当前两个存量会话均未上报生命周期：终端发现正常，不等于状态获取正常。Pi 集成文件存在但会话未上报，另一路 Agent 类型尚未识别。微信公开 Dock 未读标记当前无法读取，未完成来信提醒正向验收。模型连接仍需本人系统授权；日历真实账号与多屏实机验收尚待完成。飞书继续延期。

不得把 `unknown` 当作空闲，把 `idle` 当作事项完成，或将隔离测试等同于用户实际会话已接通。优先级、根因证据与接手入口见 [开发交接](../handoff/v0.5.0-beta.3.md)。
