# haochen 0.3.2

这是一次围绕“像桌面伙伴一样自然说话”的完整体验升级。短回答不再常驻占住桌面，而是以轻量漫画气泡出现；需要时可以一键展开完整会话。与此同时，首启称呼、长期用户档案和自定义 OpenAI 兼容模型形成了可用的完整闭环。

## 主要变化

- 每条短结果默认显示 20 秒；鼠标停在气泡内会暂停计时，移开后继续剩余时间，新结果不会继承上一条的余额。
- 短气泡提供小型关闭、发送和展开图标；展开完整会话时保留尚未发送的草稿。
- haochen 的唯一名字固定为小写英文 `haochen`，没有中文名；只有经过用户确认的称呼才会写入长期档案并注入对话。
- 首启和设置页均可配置 OpenAI 兼容模型的 URL、模型 ID、显示名称与 API Key，并可先测试连接再保存。
- API Key 只存入 macOS Keychain；公网 URL 强制 HTTPS，失败保存会回滚到原配置和原凭据。
- 设置和首启界面完成信息层级、中文文案、无障碍名称与按需展开优化。
- 人物继续沿用成年像素眼镜小哥、黑色连帽衫和暖橙肤色的全身形象，不走卡哇伊化路线。

## 安装

推荐使用 Homebrew：

```bash
brew tap yangwz1993-gif/haochen
brew install --cask haochen
open -a haochen
```

已安装旧版时运行：

```bash
brew update
brew upgrade --cask haochen
```
