# haochen 0.3.3

这是一个升级安全性热修复，解决旧版用户启动后可能出现、且在 haochen 退出后仍无法关闭的 macOS 钥匙串授权窗口。

## 修复内容

- haochen 启动和配置状态检查不再允许 macOS 弹出系统钥匙串授权框。
- API Key 迁移到稳定签名专用的新 Keychain 空间，避免触发旧版 ad-hoc 签名条目的访问控制。
- 升级后如果需要重新配置 Key，haochen 会在自己的“连接模型”页引导完成，不再留下无法关闭的系统窗口。
- 旧 Keychain 条目不会被自动读取或删除，避免再次触发授权和意外丢失凭据。

## 升级后需要做什么

首次启动 0.3.3 时，请在 haochen 内重新输入一次 API Key 并点击“保存并验证”。这一次操作会将 Key 安全保存到新的 macOS Keychain 条目，后续升级无需重复填写。

## 安装

推荐使用 Homebrew：

```bash
brew tap yangwz1993-gif/haochen
brew upgrade --cask haochen
open -a haochen
```

尚未安装时：

```bash
brew tap yangwz1993-gif/haochen
brew install --cask haochen
open -a haochen
```
