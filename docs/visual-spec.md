# haochen 视觉规范（Visual Spec）

> 版本：v1.0 ｜ 作者：产品 ｜ 用途：**P3 三 UI（对话/配置/桌宠）并行开发前必须冻结的设计规范**。三个前端 agent 共同遵守，保证双入口（桌宠气泡 / 完整窗口）视觉统一。
> 配套：同目录 `interaction-spec.md`（交互规范）。二者都是 P3 的前置输入，改动须走总会话收口。

---

## 0. 设计基调

**一句话**：像素复古质感 + 暖米白护眼 + 深描边 + 圆角 + 小尾巴（指向桌宠）。像一位"戴着眼镜的技术宅在跟你聊天"。

- **气质**：亲切、可信、有生命力；不冰冷、不花哨。
- **来源**：参考项目（haochen-reference）的像素眼镜小哥形象 + 气泡样式，但**更紧凑、更现代**（避免像素级照搬）。

---

## 1. 色板（Color Tokens）

| Token | 值 | 用途 |
|-------|----|------|
| `color-bg` | `#fdf6e3` | 主背景（米白，暖、护眼） |
| `color-surface` | `#fffaf0` | 卡片/气泡浅层表面 |
| `color-ink` | `#2b2b22` | 主文字 / 深描边（深墨绿棕） |
| `color-ink-soft` | `#5c5c50` | 次级文字（辅助说明、时间戳） |
| `color-line` | `#2b2b22` | 描边（主） |
| `color-line-soft` | `#c8c0ac` | 分割线 / 弱描边 |
| `color-accent` | `#3a7d5c` | 强调（成功/确认/品牌点，深绿） |
| `color-info` | `#5b7db1` | 信息/感知状态（"正在看屏幕"） |
| `color-warn` | `#b8860b` | 警告（需要确认） |
| `color-danger` | `#b04a3a` | 错误 / 需要用户注意（angry 姿态） |

> 全局仅用这一套 token，禁止 UI 里硬编码色值。暗色主题后续在 token 层映射，不重写配色逻辑。

---

## 2. 描边 / 圆角 / 尾巴

| 项 | 规范 |
|----|------|
| 描边宽度 | 主描边 **2px**（`color-line`）；弱分割线 1px `color-line-soft` |
| 圆角 | 气泡/卡片 **16px**；小标签/按钮 **8px**；输入框 **12px** |
| 尾巴 | 气泡右下 **小三角**，指向桌宠；大小 ~ **14×14**；描边/填充与气泡一致 |
| 阴影 | 轻投影（非必须）：`0 2px 8px rgba(43,43,34,.10)`（拉开层次，不喧宾夺主） |

---

## 3. 字体（Typography）

- **正文字体**：系统无衬线（`-apple-system, "PingFang SC", "SF Pro", sans-serif`）；代码/终端内容用等宽（`"SF Mono", Menlo, monospace`）。
- **字号/行高**（中英混排偏舒适）：

| 级别 | 字号 | 行高 | 用途 |
|------|------|------|------|
| `title` | 15 | 1.4 | 气泡/窗口标题 |
| `body` | 14 | 1.6 | 正文对话 |
| `body-sm` | 12.5 | 1.5 | 次级说明、时间戳、工具摘要 |
| `code` | 13 | 1.5 | 代码块（等宽） |

- 正文允许自动断行；英文单词不截断；中文不出现悬挂标点。

---

## 4. 桌宠（像素眼镜小哥）

- **形象**：像素/复古风、戴眼镜、传达"技术宅·聪明·可信"。
- **三姿态**（随状态自动切换）：

| 姿态 | 触发 | 表情 |
|------|------|------|
| `idle` | 空闲 | 平静，偶尔眨眼/微动（有生命感） |
| `thinking` | 思考/推理 | 手托腮 / 眼向上瞟 |
| `angry/alert` | 出错/需注意 | 皱眉 |

- **尺寸**：常驻 **96×96**（可缩放）。姿态切换用**轻过渡**（非硬切），避免突兀。
- 桌宠常驻屏幕角落，无 Dock 图标（`LSUIElement`），Accessory 形态。

---

## 5. 动效节奏（Animation）

**分级原则**：MVP 级动效（P3 必须）与精细动效（P6）分开。

### MVP 级（P3 实现，必须有）
| 场景 | 动效 | 时长 |
|------|------|------|
| 唤起气泡 | 气泡从桌宠方向淡入+上滑 ~10px | 180–220ms |
| 动态对话流 | 输入→思考→结果 **逐条弹出**（每条淡入+轻微上移） | 每条 180ms |
| 姿态切换 | 桌宠 idle→thinking→idle 轻过渡 | 160–220ms |
| 流式文字 | 打字机效果（逐字/逐词浮现） | 跟随生成速率 |
| 收起 | 气泡缩小+淡出（指向桌宠） | 150ms |

### 精细动效（P6 打磨，本期不强求）
- 弹性缓动、气泡贴边露头、工具卡折叠展开动画、感知提示的呼吸/扫描效果、成功/失败的状态动效。

> 原则：**动效克制、有生命感**，不干扰阅读；一律 `ease-out`，不滥用弹性。

## 6. 组件规范（三 UI 共用）

### 6.1 气泡（桌宠对话）
```
┌──────────────────────────────────┐
│  [👓] haochen            ✕       │  标题行：小图标+名+收起
├──────────────────────────────────┤
│  「我正看一下你的屏幕…」            │  感知提示（color-info，弱化）
│  （L1 短结）…                     │
│  （L2 详答）…                     │  对话流：逐条弹出
│  [输入框]                  ➤      │  快捷输入，融入气泡
└──────────────────────────────────┘
    ↘ 右下尾巴（指向桌宠）
```
- 宽：**≤420px**，最大高度 ~70% 屏；内容溢出滚动。
- 感知提示：`body-sm` + `color-info`，与正文弱区分。

### 6.2 完整窗口
```
┌──────────┬──────────────────────────────┐
│ 会话侧栏   │ 对话区                        │
│ (title)   │  用户消息                      │
│ · 列表…   │  haochen 消息（L1+L2）        │
│ + 新会话  │  [工具卡] ▸ 已读屏 ✓ ▸ 已运行 ✓│
│ 设置入口  │  [输入框]              ➤       │
└──────────┴──────────────────────────────┘
```
- 侧栏宽 220–260px；会话项高 40px；当前项高亮（`color-accent` 左条）。
- 对话气泡：用户居右（`color-surface`）、haochen 居左（`color-bg`），最大宽 ~72%。

### 6.3 工具卡（工具过程可视化）
- 可折叠卡片：标题行 = 图标 + 工具名 + 状态（✓/运行中/…）+ 摘要。
- 展开显示：输入/输出摘要（命令、读屏内容片段）、耗时。
- 状态色：成功 `color-accent`、进行中 `color-info`、失败 `color-danger`。

### 6.4 状态提示
- 感知态（在看屏幕）：`color-info` 文本 + 桌宠"眼睛对准屏幕"姿态。
- 警告态（需确认"读吧/不读"）：`color-warn` + 两个明确按钮（主按钮实心、次按钮描边）。
- 错误态：`color-danger` 文本 + 可重试入口。

---

## 7. 双入口一致性（验收项）

- 桌宠气泡与完整窗口使用**同一套 token / 描边 / 圆角 / 字体 / 姿态**。
- **同一会话、同一 AI 头像**（像素小哥）贯穿两入口。
- 切换入口时视觉不"变了个产品"。
