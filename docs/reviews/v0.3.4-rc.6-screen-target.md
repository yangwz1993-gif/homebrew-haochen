# v0.3.4-rc.6：提问时感知窗口，固定阅读对象

2026-09-11。所有者已认可前轮初始化修复，本轮授权两个体验功能：提问时识别切屏，阅读确认前固定目标。真实文字/结构/图片资源优先，截图仅辅助。其余二期计划不在本轮范围内。

## 根因与实现

旧代码仅在应用激活时记 PID，没有把每轮页面状态接入模型上下文；工具在确认完成后才找前台对象。PID 不能区分同应用多窗口或同窗口不同页面。旧截图还会等图片下载完成后才采集。

- 入队时保存窗口元数据：PID、CG window ID、标题和文档/网页 URL 的摘要；正文和截图不在授权前读取。元数据查询仅在提问时执行，不主动弹窗、不后台持续读正文。
- haochen 取得焦点时，用已有激活监听记录的最近外部应用找窗口；优先 AX 聚焦窗口，不能用“最大窗口”替代。实测发现的 macOS 屏幕共享微型浮层已排除。
- 每轮引擎启动前冻结该消息的目标；确认框显示对应应用和窗口。确认期间即便 sidecar 更新，仍使用局部冻结目标。模型不能用 PID 参数改读其他对象。未知目标或不能显示确认时拒绝读取。
- 队列中的不同问题保留各自目标；进程重启后旧 OS 标识不复用，需要重新确认。元数据 sidecar 0600，正文不写入该 sidecar。
- 屏幕标识不同时明确注入“已切换”；标识相同也不承诺正文没变。当前问题不默认使用历史 read_screen 工具结果；明确继续历史对象时保留其上下文。普通问题不强制读屏。
- 获准后直接启动真实读取器，不额外运行一个权限自查进程；读取器内仍先无弹窗检查系统权限。首次没有身份摘要时，授权后要求回到页面重新提问，不读取授权等待后任意出现的窗口。
- 通过固定 CG window ID 匹配唯一 AX 窗口，检查页面摘要；正文和必要窗口画面在原图下载之前采集。采集后再检查窗口、页面摘要及文本块是否变化，有变化就丢弃。
- 默认不滚动，避免操作用户切换后的窗口，也不把不同滚动时刻混成“当时的一屏”。范围明确为窗口当前可访问内容，不能声称已读完整文档。
- AX 文本、标题和链接保留结构。公开 HTTPS 和合法内嵌 data 图片优先保留原字节（不重编码）；沿用图片解码、大小、类型及网络安全约束。不带凭据下载登录态资源，不把任意本地文件 URL 当图片读取授权。
- 一张原图成功不再掩盖其他图片缺失。缺失原图时附同步采集的窗口画面，并说明它只是辅助快照；纯文字正文不要求截图。取消会停止读取子进程，取消后的结果不上送。
- 修复开发读取器脚本遗留绝对路径，开发与打包均指向当前代码，不回落到其他历史安装的读取器。

## 能力边界

当前通用读取通道是 macOS AX，不宣称已集成浏览器 DOM 扩展或每个应用的私有内容接口。AX 未暴露的正文、登录态原图、过大图片可能无法完整取得；结果明确给出范围和缺失信息。

不在授权前保存正文，因此无法还原授权前的任意历史帧。如果页面在等待期间只更新正文、标题/URL 保持相同，只能取得同一目标在确认后的内容；采集期间发生变化则拒绝。完全动态、身份不可观测的页面不承诺像素级时间冻结。
