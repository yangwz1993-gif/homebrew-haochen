# v0.3.4-rc.3：视觉与交互验收候选

日期：2026-09-11。依据所有者的《091111606验收.md》及确认后的三项改造方案。
本轮由所有者验收，不安排独立审美 agent，不进入二期、不更新线上 Cask / Release。

## 完成内容

1. 短气泡、详情及完整会话使用同一个 appearance 模块。中性白底、深灰文字、墨绿操作，减轻描边和标签。
2. 单层 32 px 标题栏，保留真实 macOS 红黄绿控件；短标题弱化、长标题省略，首轮引导标题显示为“会话详情”。收起使用图标，支持 Esc / ⌘W / 系统关闭。
3. 面板按人物周围的空闲区域放置；优先完整可读面积，适配屏幕边角及小屏幕。展开 180 ms、收起 130 ms，固定尺寸滑动 8 px 并淡入淡出，不再拉伸文字或移动人物。
4. 紧凑/完整输入框同步草稿，同一回合再次展开恢复阅读位置。关闭时取消失效的延迟定位任务；使用窗口自身的 Qt slot 承接定时回调，修复组合回归中发现的生命周期崩溃。

## 本机实际使用检查

使用最终冻结 App、内嵌引擎和隔离临时目录中的合成历史，通过原生 UI 操作检查：

- 点击人物 → 短气泡 → 展开；白底一致，系统标题不再额外占一行，红黄绿按钮仍可用。
- 修改详情草稿 → 收起 → 短气泡看到同一草稿；再次展开仍保留。
- 阅读滚动值 1200 → 收起 → 再展开，仍为 1200。
- 收起图标、Esc、⌘W 及原生关闭均返回人物；普通完整会话可从菜单打开并正常关闭。
- 最终安装版详情窗口从 `(734, 133, 680, 560)` 拖到 `(664, 173, 680, 560)`，人物始终为 `(1317, 709, 112, 112)`；关闭后人物位置不变。坐标来自只读窗口元数据。
- 关闭隔离进程后，用原有用户配置启动 `/Applications/haochen.app`。
- 正常环境当前停留在“连接模型”页，存在“授权已有 Key”入口；旧 Key 的 macOS 授权需要所有者亲自确认，未代点该按钮，未要求重新填写 Key。真实对话验收需先完成这一步。

这不是实时模型质量或真实钥匙串授权验收：没有发送用户聊天内容、没有操作 API Key / 系统授权。
原有配置、记忆及会话未清理；旧安装 App 与 rc.1 / rc.2 DMG 已移入系统废纸篓，而非另建可搜索的 App 备份。
