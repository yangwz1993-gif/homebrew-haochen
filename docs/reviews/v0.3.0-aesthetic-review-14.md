# Haochen v0.3.0 Aesthetic Review — Round 14

## Verdict: NOT PASS

The candidate clears the three priority interaction gates: `⌘1` routing is usable from avatar, compact composer, and full conversation; the avatar context-menu second action reaches the full conversation before and after restart; explicit and natural Markdown bold output is clean in the compact bubble and readable in detail.

It is not ready for a strict release-quality pass because conversation history disappeared after two exact candidate/engine process restarts. Multiple completed topic titles and the stopped long-answer session were visible before termination; after restart, `⌘1` opened a sidebar containing only `新会话`. This is repeatable user-visible data-loss risk and outweighs the successful core interaction gates.

The visual system is coherent and personable, but several conspicuous polish defects also prevent the required “no obvious flaws” bar: the avatar has no visible discovery cue, short full-window conversations leave an excessive empty field, the detail heading is generic, full-view send affordance is tiny and inconsistent with the labelled compact button, and Settings is cramped/low-contrast with clipped content at its default size. Escape did not close Settings.

## Gate summary

- PASS — Foreground avatar single-click composer; `⌘1` avatar → full; compact/full `⌘1` no dead end.
- PASS — Context-menu second action by right-click, `Down`, `Down`, `Enter`; same result after restart.
- PASS — Explicit `**巴黎**` intent renders as clean `巴黎`; natural bold place names render without Markdown control characters.
- PASS — Brief/detail/follow-up, long-answer stop semantics current and reopened, distinct topic titles, `⌘,`, and read-screen refusal.
- NOT ADJUDICATED — Native restore after maximize due missing CUA window controls.
- NOT ADJUDICATED — No-credential error/Retry flow because the persistent CUA launcher retained the valid fixture environment. No real credential was entered or exposed.
- FAIL — Full conversation history across candidate/engine restart.

## Required release fixes

1. Persist and restore all completed/incomplete sessions across candidate/engine termination; verify sidebar titles and stopped-generation semantics after restart.
2. Add a discoverable first-action cue to the avatar without weakening the minimal desktop-companion character.
3. Tighten the short-conversation layout, use a topic-specific detail title, and make the full-view send control consistent and legible.
4. Improve Settings default viewport, contrast, and Escape behavior.
5. Re-run the no-credential fixture separately and prove localized error copy, Retry counts 1–3, Settings navigation, and complete error history.
