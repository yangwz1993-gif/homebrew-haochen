# v0.3.4-rc.2：Key 保存授权修复

日期：2026-09-10。本修订处理 rc.1 中“连接验证成功、保存 Key 失败”的升级阻断问题。

## 行为边界

- 启动、引导状态检查、设置状态刷新：继续采用无交互读取，绝不主动弹 macOS 钥匙串窗口。
- 用户主动点击“保存并验证”或“删除 Key”：才允许系统显示钥匙串授权。用户可选允许、始终允许或拒绝。
- 旧 Key 无法静默读取时，保存新 Key 不再先失败；事务回滚也不会把读取不到的旧 Key 当成不存在而删除。
- 一次“允许”的成功写入只保留在当前进程的内存中，避免立即再次请求读取授权；不写入 API Key，不改写条目 ACL。

## 验证

- 391 项质量检查通过，覆盖率 82%，包括保存授权、静默保存、旧 ACL 读失败保护、引导异步保存与设置异步保存回归。
- legacy DMG 与 App 均经 `codesign --verify --deep --strict`；DMG `hdiutil verify` 通过。
- DMG SHA-256：`faabc94a720b98a99df11c546e5c81befd566768330a95c9cdd17953936361f9`。

macOS 实际授权属于用户凭据操作，需由所有者在新版中亲自点击“保存并验证”后确认；本记录不把自动测试当作真实许可通过。
