## 升级发现与修复

0.3.3 的现存 Key 未丢失，旧条目信任相同指定签名，但 partition_id 含旧包 cdhash；因此不能假设自签升级自动继承访问权。本轮新增显式“授权已有 Key”入口：启动/状态查询/普通保存不自动弹系统框，只有点击授权入口才允许后台交互读取。取消后可重试；单次许可仅在当前进程缓存，不落盘，不改 ACL，不输出 Key。

该恢复路径的成功、取消和 UI 不阻塞已有自动测试；真实 macOS 授权需要用户亲自完成，本轮没有代为输入密码或点击许可，也不声称真实授权已通过。
