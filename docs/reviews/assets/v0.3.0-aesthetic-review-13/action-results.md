## 有效凭据场景

### A1 — 右键人物（失败）

- 前置：仅候选与其 engine 运行，人物可见。
- 动作 1：对 AX 人物目标发送一次右键，立即获取 CUA 可见截图。
- 动作 2：在人物衣服可见像素内坐标右键，立即获取 CUA 可见截图。
- 重启候选后动作 3：再次在人物中心可见像素右键，立即获取纯视觉截图。
- 结果：三次截图均只见 128px 人物与鼠标点击指示，没有任何上下文菜单。无法点击要求中的“打开完整对话”。
- 对照：同一候选的菜单栏功能菜单可正常显示“打开对话 / 新会话”，说明完整对话自身可达，但不替代失败的右键入口。

### A2 — `⌘,` 三场景（通过）

- 桌宠可见：先单击人物取得前台，再按 `⌘,`；窗口标题变为“haochen 设置”。
- 桌宠小窗：输入框可见时按 `⌘,`；窗口标题变为“haochen 设置”。关闭设置后回到原小窗。
- 完整会话前台：按 `⌘,`；窗口标题变为“haochen 设置”。关闭设置后回到完整会话。
- 三次设置页均为同一米白卡片界面。

### A3 — `⌘1` / `⌘N`

- `⌘1`：重启候选、人物前台可见并先单击聚焦后按下；立即截图仍只有人物，未打开完整会话，也无其他反馈。该动作与成功的 `⌘,` 使用同一 CUA Command 输入路径。
- `⌘N`：完整会话中按下；内容区立即清空并出现新的“新会话”，旧主题保留在左栏。通过。

### A4 — 小窗简答、详情与追问

- 问题：“用一句话解释为什么天空是蓝色的。”
- 结果：依次显示“收到，我接住了”→“正在组织回答”→一句简答，并显示“继续问 / 查看详情”。
- 点击“查看详情”：打开“当前会话详情”，右上明确显示“收起 Esc”，摘要使用绿色“结论”标签。
- 问题：“推荐一个适合上海秋天的周末散步安排。”
- 小窗结果原样显示 `**武康路—衡山路**`。
- 点击“继续提问”后追问：“如果下雨呢？”
- 小窗结果原样显示 `**上生·新所 → 静安寺**`，内容能承接上文。
- 点击详情：同样两处内容在详情页正确渲染为粗体，并有“结论 / 依据与细节”分层。

### A5 — 可见长回答中止与重开（通过）

- 问题：“请分十个小节、至少2000字详细分析城市公共空间如何影响邻里关系，并给出多个案例。”
- 等到正文已显示多个小节且“停止生成”按钮仍在，再点击停止。
- 当前视口：保留停止前正文；底部橙色显示“已停止生成 · 上述内容未完成”；AX 同时包含“已停止生成，以下是停止前的未完成内容 / 未完成内容”。
- 点击窗口关闭回到人物，再由功能菜单“打开对话”重开。
- 重开结果：仍停留在相同正文位置并保留橙色“已停止生成 · 上述内容未完成”。

### A6 — 两个主题标题（通过）

- 会话 1：“比较手冲咖啡与意式浓缩的风味特点，用三句话。”
- `⌘N` 新建后，会话 2：“给朝北阳台推荐三种耐阴植物，并说明浇水频率。”
- 左栏同时可见“比较手冲咖啡与意式浓缩的风味…”与“给朝北阳台推荐三种耐阴植物，…”；另有长回答标题“请分十个小节、至少2000字详细…”，三者可明确区分。

### A7 — 窗口与设置凭据（通过）

- 完整会话执行窗口绿色钮的“zoom the window”辅助动作：先最大化，再次动作恢复；两态内容、侧栏、输入区可用，恢复后没有出现窄窗或横向挤压。
- 设置页 API Key 是 secure text field；有效态只显示“已验证，输入新 Key 可替换”，未出现明文凭据。
- 四边摆放：通过 CUA 将人物连续向左移动且人物仍可重新连接和显示；工具无法可靠给出全局窗口坐标，未形成四个边缘的可裁决证据，未据此判产品缺陷或通过。

### A8 — 读屏拒绝（通过）

- 问题：“请读取我当前屏幕上的文字并概括，不要猜测。”
- 小窗显示“👀 准备读取当前屏幕”，说明需要当前活跃窗口内容，并提供“读吧 / 不读”。
- 点击“不读”。未读取屏幕，立即回到人物。
- 打开完整历史：工具卡显示“🖥 read_screen 未执行 · 未获授权”，拒绝语义明确且没有再次索取权限。
