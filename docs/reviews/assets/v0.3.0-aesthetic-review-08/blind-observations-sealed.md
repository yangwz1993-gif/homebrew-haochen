# Round 8 自由盲测封存（2026-09-09 02:43 CST）

> 仅记录在读取定向检查项后的自由使用观察；此文件此后不回改。

- 指定构建可直接启动，桌宠位于屏幕右下。首次状态的辅助功能树有“点一下我，随时开聊”，但在完整桌面上气泡没有稳定浮到前台；手动唤起后输入气泡才清楚可见。
- 输入态紧凑，输入框、发送按钮与快捷键提示容易理解；尾尖视觉上能对准人物中心。
- 在题目“你好，用一句话介绍自己。”发送后，没有经历可感知的接单/处理中阶段，约 1.6 秒即显示“API Key 无效或格式不正确”。
- 错误气泡本身只出现一个中文错误块，提供“检查设置”和“重试”，信息没有乱码或英文路径泄漏。
- 从错误进入设置后，供应商/模型/思考档层级清楚，但“有效凭据”场景被设置页判定为“当前凭据验证失败”，使短问题、追问、详情、退场等核心体验无法继续。
- 右键桌宠能看到“打开气泡 / 新会话 / 设置… / 退出”，文字自然；菜单是系统样式，与桌宠气泡风格相比略显割裂，但仍可理解。
- 第一眼最影响信任的是：任务给定的有效隔离环境与 Keychain 项均存在，App 却立即把它判作格式错误；这不是回答质量问题，而是直接阻断真实对话。
