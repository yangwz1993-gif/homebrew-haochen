## 问题（按严重度排序）

### P1 — ⌘, 无法打开设置

- 用户动作：在完整会话窗口处于前台、空输入框获得焦点时按 ⌘,；为排除偶发，又重复一次。
- 实际表现：窗口、焦点和内容均无变化，设置窗口没有出现。随后从菜单栏点击“设置…”立即成功打开同一设置窗口。
- 期望表现：按 ⌘, 应直接打开“haochen 设置”，与菜单栏“设置…”一致。
- 为什么阻断门禁：这是明确要求的键盘入口；没有反馈、也没有到达目标，构成静默死路。
- 证据：有效环境矩阵中的“⌘,”行与设置可达性对照。

### P1 — 桌宠右键没有上下文菜单，“打开完整对话”不可达

- 用户动作：在桌宠可见且没有其他弹窗遮挡时，先右键人物中心，再右键其可访问图像元素，并用另一种右键按钮表达复验。
- 实际表现：三次都没有出现上下文菜单；只看到人物姿态/悬停视觉变化。没有“打开完整对话”项，因此无法从该入口实际到达完整会话。
- 期望表现：右键桌宠应稳定出现包含“打开完整对话”的菜单，点击后打开完整会话。
- 为什么阻断门禁：这是本轮明确指定的鼠标入口；用户得到零文字反馈，无法发现或完成目标。
- 证据：有效环境矩阵中的“Pet right-click”行；同一矩阵记录了 ⌘1 和菜单栏路径可正常打开完整会话，说明目标窗口本身可用，失败集中在右键入口。

## 通过项

### 人物与首次观感

首次看到的是清晰的成年像素工程师：橙棕肤色、黑色乱发、橙色眼镜、深色连帽衫。96×96 桌宠在桌面尺度仍能一眼辨认，轮廓无缺损、像素缩放不糊。人物既有风格和肤色应保持，不建议重做人设。

### 含糊问题、简答、详情与追问

“这个怎么弄？”自然触发读屏许可，而不是假装知道屏幕内容；许可文案解释了需要当前活跃窗口，并提供“读吧 / 不读”。拒绝后没有读取屏幕，完整历史给出自然的澄清请求。

“法国的首都是哪里？”在小窗中直接给出“巴黎（Paris）。法国首都是巴黎。”；“继续问”和“查看详情”层级分明。完整会话中结论卡与“依据与细节”卡分组清楚，继续问“为什么巴黎会成为首都？用一句话回答。”得到简洁结论，输入始终可达。

### 中止与续接

在完整会话请求至少 1200 字、10 个编号段落的城市公园文章。正文出现并滚到第 9 段后点击红色停止按钮：

- 当前视口末尾明确显示橙色“已停止生成 · 上述内容未完成”；
- 残片保留在未完成卡片中，没有被包装成“结论”；
- 关闭窗口后用 ⌘1 重开，仍回到同一第 9 段残片和未完成标记；
- 紧接着问“继续，用一句话告诉我刚才停在哪里”，回答准确指出“9. 周末野餐的一桌人”并引用末尾“就能‘拥有’”；
- 用户气泡只显示用户原句，没有内部上下文标签。

### 多会话与标题

通过菜单栏连续新建会话，回到桌宠完成三种不同主题的首问。完整会话侧边栏标题分别为：

- 今晚在城市里怎么看到木星？
- 番茄炒蛋先炒蛋还是先炒番茄？
- 蓝鲸一天大约吃多少磷虾？

三条可区分，无突兀冒号、无模型名或内部技术文本。⌘1 正常打开完整会话，⌘N 正常创建并选中新会话。

### 临时气泡、状态视觉与窗口布局

“17 加 25 等于多少？”返回“17 + 25 = 42。”，按钮可达；外部 CUA 计时 22,001 ms 后气泡已自然退场，仅用来复验约 20 秒后的状态，不据此声称应用内部精确驻留时长。再次唤起后问“怎么算的？用一句话说。”得到正确的进位说明，并能打开详情看到两轮完整内容。

输入态提示、处理中状态和停止操作、结果态主次按钮都可理解。最大化与恢复后侧边栏、内容、输入与发送均可达。上、下、左、右边缘均会让气泡向屏幕内侧展开，尾尖位置随边缘调整，没有文字裁切或按钮出界。

### 隐私拒绝与错误 fixture

再次请求读取当前屏幕时，应用明确展示许可卡；点击“不读”后没有暴露屏幕内容。

错误 fixture 中输入“你好”得到中文错误：“API Key 无效或格式不正确。请打开设置重新配置后再试。” 未出现 key 值、路径、堆栈或内部异常。连续点击 Retry 三次后，同一气泡依次显示第 1、2、3 次重试仍未连接成功，按钮持续可用、没有重复创建会话或崩溃。

“检查设置”进入恢复页，显示“当前凭据验证失败”、空的安全输入占位“重新输入有效 API Key”和“保存并验证”，底部状态同样是中文；没有凭据值可见。未提供有效凭据，因此没有输入或提交任何 key。完整会话历史保留用户“你好”和对应中文错误卡；三次重试计数保持为瞬时恢复状态，没有伪造成三条新对话。
