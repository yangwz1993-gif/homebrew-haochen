### P1-1：结果气泡 hover 后离开不恢复剩余倒计时

复现路径：真实本地 OpenAI 兼容模型返回成功结果；把鼠标放在结果卡内 7,212 ms，结果按预期保持；再把真实指针移到另一应用左上角、明确离开 380 × 153 的结果窗口。离开后继续用单调时钟观察，20,349 ms 时结果仍在，最后只能点右上角关闭。

对照组在不 hover 时于 19,978 ms 自动退场，证明默认计时器本身工作。失败点是 hover 后的 leave 没有恢复剩余倒计时，会让始终置顶的结果气泡无限驻留，是直接可见、持续遮挡的核心交互缺陷。

### P2-1：从中断点恢复的试问页缺少“上一步”，首启配置不可逆

首次流程中，自定义模型保存成功后进入试问页，页面同时有“上一步”和“开始使用”。关闭候选并以相同隔离 Home/Keychain 正常重启，确实准确恢复到试问页，但“上一步”消失，只剩“开始使用”。因此用户无法按要求返回模型页检查或修改已保存配置，也无法在首启向导内验证自定义模式和字段水合。

这是上轮“续办退回错误页面”的一半修复：恢复位置正确了，但恢复后的导航历史/可逆性仍丢失。完成首启后，设置页能证明 URL、模型 ID、显示名正确水合，空 Key 可以复用 Keychain 凭据；这不能替代首启阶段应存在的返回能力。

证据对照：[07-trial-before-interrupt.jpg](assets/v0.3.2-aesthetic-review-03/07-trial-before-interrupt.jpg)、[08-resume-exact-trial.jpg](assets/v0.3.2-aesthetic-review-03/08-resume-exact-trial.jpg)、[11-settings-edit-hydrated.jpg](assets/v0.3.2-aesthetic-review-03/11-settings-edit-hydrated.jpg)、[12-saved-key-reused-no-reentry.jpg](assets/v0.3.2-aesthetic-review-03/12-saved-key-reused-no-reentry.jpg)。

## mock 专项覆盖说明

按要求用第二个全新隔离环境启动 `HAOCHEN_MOCK=1 HAOCHEN_SKIP_ONBOARDING=1`，候选在 UI 出现前因包内缺少 `Contents/mock-engine` 以 `FileNotFoundError` 退出；只读列举 App 内容也找不到 mock 文件。依据验收协调意见，发布包不携带开发 mock 不计作产品缺陷，只作为指定测试路径不可用的覆盖限制。

为避免放弃用户可见生命周期验证，本轮改用同一候选、已通过 UI 验证并由 Keychain 读回的本地 OpenAI 兼容模型完成成功结果计时。报告没有把真实配置路径与不可用的 mock 路径混写。
