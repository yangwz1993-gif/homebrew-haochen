### 5. 待机／思考／警示三态人物：不通过

- 待机态为盘腿坐姿的完整人物，头、躯干、手、腿和鞋均可见，没有半身平切。人物约位于 `x=2660–2870, y=1430–1660`。[待机裁图](assets/v0.3.1-aesthetic-review-02/00-initial-idle-crop.jpg)
- 思考态为抱笔记本电脑、手扶下巴的全身动作，轮廓清楚，无裁切；动态状态文案从“收到，我接住了”切换到“正在组织回答”。[思考裁图](assets/v0.3.1-aesthetic-review-02/11-thinking-full-body-crop.jpg)
- 结果态仍保留全身人物，气泡尾巴朝向人物头部，空间关系自然。[结果裁图](assets/v0.3.1-aesthetic-review-02/12-summary-full-body-crop.jpg)
- 明显缺陷：待机态脸部为饱和橙色；思考态与结果态脸部整体变成灰紫色，而耳朵和手仍保持橙色。它不是统一的环境光变化，而是同一人物在状态切换中的明显肤色不一致。按本轮硬门槛，此项直接阻断放行。
- 风格方面人物使用大头、小身体、像素卡通比例，有一定卡哇伊化倾向，和“不应卡哇伊化”的方向仍存在主观偏差。
- 覆盖限制：通过公开 UI 真实问答可稳定触发待机、输入/思考和结果态；警示态未能在模型极快返回前稳定截取。没有使用私有接口或改动配置强造状态，因此警示态的全身动作未形成可靠证据。

### 6. 四边缘拖动、气泡避让与可点击性：覆盖受限

- 候选默认位于屏幕右下边缘，已验证右边缘和下边缘组合场景：气泡向左上方避让，主体未出屏，尾巴指向人物，输入框和发送按钮可点击。[证据 01](assets/v0.3.1-aesthetic-review-02/01-first-greeting-input.jpg)
- 默认右下场景中，最终简答与“继续问／查看详情”按钮也均在屏幕内并可点击。[结果证据](assets/v0.3.1-aesthetic-review-02/12-summary-full-body-crop.jpg)
- 覆盖限制：透明无边框人物窗体无法被 CUA 的坐标拖拽稳定命中，左边缘与上边缘的成功落点、顶部翻转没有形成可信截图。没有改用私有接口或修改产品状态；因此不能声称四边全部通过。

### 7. 真实输入 → 动态思考 → 简答 → 展开详情 → 收起：通过

真实输入经候选内嵌 engine 完成模型链路，先出现“收到，我接住了／停止”，随后“正在组织回答”，最终给出简短人话结论，例如：

> 通知一响注意力就被拽走，重新进入状态要花好几分钟，所以关机静音才能护住心流。

简答信息量合适，并显示“继续问”和“查看详情”按钮。[简答与全身人物](assets/v0.3.1-aesthetic-review-02/12-summary-full-body-crop.jpg)

点击“查看详情”后打开完整对话窗口，能看到用户输入、结论和“依据与细节”；输入框与发送按钮保持可用。[展开详情](assets/v0.3.1-aesthetic-review-02/10-details-expanded.jpg)

按 Esc 可收起详情并回到桌宠；Return 发送、Command+Return 换行、Esc 收起均已实操。简答气泡会自动退场，状态切换流畅，没有卡死或核心流程中断。
