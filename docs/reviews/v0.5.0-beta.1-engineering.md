# 0.5.0-beta.1 本地工程验证

日期：2026-09-13。分支：`feat/v0.5-dashboard`。这是本机验收候选，不是公开发布或用户验收通过的声明。

## 实现范围

生产界面使用随 App 打包的 HTML/CSS/JavaScript，由原生 NSPanel/WKWebView 承载，与已有 Qt 桌宠共用原生事件循环。没有演示数据、CDN 脚本、模拟桌面、全屏透明鼠标遮罩或第二个 HTML 桌宠。

Otty 使用官方 CLI；Chrome 使用配套 MV3 扩展、逐站授权与 native messaging；日历使用 EventKit 的显式用户授权；文件渠道仅限用户选择的入口。事项刷新保留来源、范围、检查时间和失效信息。可选后台摘要使用真实引擎，但隔离凭据、会话、工具与项目提示文件。

## 本轮发现并修正

- WebKit 原生导航回调 block 元数据需在实际方法安装时正确绑定；阻断外部导航后仍能正常使用生产文档。
- 首次桥接就绪早于文档完成；宽度变化挤压内容；状态刷新替换按钮导致点击丢失；保存错误在滚动区域外不可见。
- 任务修订号使用独立随机值，旧任务不能覆盖编辑、暂停或删除。
- 关闭连接、撤回站点权限和收缩日历范围必须清除派生内容并使旧采集失效。
- 采集阶段的取消也需传到后台摘要，不能仅停止已经启动的模型进程。
- 长正文超限明确标注部分读取，去除重复正文别名，并保留全量返回正文的变化指纹。
- 日报不把初始 Agent idle 快照当作完成；来源新增/消失须与断连、局部快照、离线时段区分。
