# v0.3.4-rc.4：连接与权限反馈修复

日期：2026-09-11。依据所有者《0911-1720反馈.md》及随后确认的单按钮方案。
本轮只修复一期反馈，由所有者验收；不进入二期，不发布到线上 Homebrew。

## 已完成

1. 首启、设置和自定义模型连接入口统一为“连接模型 → 连接中… → 已连接 ✓”。不再并列展示授权、保存、重新授权按钮。更换和删除 Key 收入更多菜单，删除仍需确认。
2. 有新输入时验证新 Key，通过后才尝试保存；没有新输入时读取原 Key，仅必要时请求用户确认 macOS 许可，取得许可后继续连接验证。取消授权会停止流程，失败不清空输入，原 Key 保留。
3. 设置后台状态不能将新草稿误标为已连接。自定义 URL 改变时要求新 Key，防止旧 Key 被发送到新地址；重连已有自定义模型保留原协议。
4. 权限页按照系统检查结果分别显示“管理权限 / 去开启 / 重新检查”。已经授权时说明无需重复操作、重装可能保留历史授权；检查异常显示无法确认。管理入口只打开系统设置，不再次请求授权。
5. 首启和设置复用会话的白灰、墨绿、细边框样式。首启默认 600 × 460，更多按钮使用独立的 30 px 命中区域。签名说明不再暗示所有正式包都已经 Apple 公证。
