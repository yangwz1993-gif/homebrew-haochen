# 外部凭据轮换清单

> 状态：**等待凭据所有者处理**。在以下项目完成前，不得宣称 v0.2 正式发布安全闭环。

旧工程和迁移初始历史中发现过以下明文材料：

1. 本地自签代码签名私钥、P12、证书和 Keychain 口令；
2. 一个第三方模型服务 API Key；
3. 自签证书指纹和旧签名操作说明。

新仓库当前工作树已删除这些材料，并会重写尚未推送的本地 Git 历史。由于凭据曾以明文存在，删除文件不能恢复其机密性。

凭据所有者必须：

- 在对应模型服务控制台撤销旧 API Key，创建新 Key，并仅通过 App 安全配置入口录入；
- 删除/停用旧自签 identity、P12 和专用 Keychain，不在 v0.2 中复用；
- 为正式发布准备 Apple Developer ID Application 身份和 notarytool Keychain profile；
- 检查任何可能接收过旧文件的备份、同步盘或远端仓库，必要时同步清理并轮换。

完成后请在发布验收记录中只填写“已轮换/吊销 + 日期 + 操作者”，不要记录新凭据内容。
