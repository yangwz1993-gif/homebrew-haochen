# haochen v0.2.0 Release Notes

> 粘贴到 GitHub Release v0.2.0 的描述框（创建 Release 时用）。

## haochen 0.2.0

桌面 AI 伙伴全面升级：更安全、更稳定、更好用。

### 安全

- 会话删除仅允许操作私有会话目录内文件，拒绝路径穿越/越界/符号链接；删除带二次确认与撤销
- 远程图片仅允许公网 HTTPS 并逐跳重校验（防 SSRF/本地文件读取）
- 用户提问不再落盘（仅保留派生的看图意图布尔值）；本地数据目录统一 0700/0600 权限
- API Key 存入 macOS Keychain，配置文件只留环境引用

### 稳定性

- 引擎退出不再卡 UI（后台进程组回收，杜绝孤儿进程）
- RPC 请求 5 秒超时 + 崩溃/停止统一结算；协议错误脱敏记录
- 30 秒健康探针，引擎无响应自动重启；会话与未发送输入崩溃后可恢复

### 体验

- 首次启动单一向导：欢迎 → Key 验证 → 按需权限 → 试问（可中断续办）
- 流式回答 50ms 节流；回看不强制滚底，带“回到最新”
- 双入口输入队列可见、可取消；工具卡支持取消/重试/打开产物/耗时
- 原生菜单栏（⌘1 对话 / ⌘, 设置 / ⌘N 新会话 / ⌘Q 退出）、窗口记忆、多屏气泡定位、Reduce Motion 支持

### 安装

```bash
brew tap yangwz1993-gif/homebrew-haochen
brew install --cask haochen
```

SHA-256: `e516146dbc868edf1251962e331f4b51b574eae7ba182b9d047bd420567ea9bc`

说明：本版本由发布者自签身份签名（与 0.1.x 相同的分发模式），安装时 Cask 会移除系统隔离标记；首次使用读屏/看图功能需在系统设置中授权。

### 回滚

如遇问题：`brew uninstall --cask haochen` 后从历史 Release 安装旧版 DMG。
