# haochen 0.6.2-beta.2 交接文档

> 本轮在 0.6.2-beta.1 基础上继续开发，聚焦「内网模型应用内接入 + Hi 精准跳转 + 分发就绪」。
> 分发形态：legacy（稳定自签、未 Apple 公证），已授权**内部** Homebrew 分发。

## 一、本轮做了什么

### 1. 内网模型（CodeWiz）应用内闭环
- 向导「连接模型」下拉收拢为 **外网（DeepSeek / 自定义）** 与 **内网（CodeWiz）** 两档；内网档下新增**模型选择器**（Kimi / GLM / Gemini…）。
- 填**公司邮箱 + API Key** → 点校验：自动带上本机已登录 codewiz-cc 的 **SSO cookie + X-Adapter 头**；**跳过会 500 的 `/models`，直接用 `/chat/completions` 试答**；通过后写 `~/Library/Application Support/haochen/codewiz.json` 并设为默认模型。
- 模板 `config/models.json` 内置 `codewiz` / `codewiz-gemini`（仅 `$ENV` 占位，无密钥）；`config/auth.json.template` 加了 env-ref 条目；`_seed_indirect_providers` 迁移让老用户 auth.json 也补上。
- 关键文件：`app/haochen_app/onboarding.py`、`app/haochen_app/codewiz.py`、`app/haochen_app/key_validation.py`（`probe_completion_only`）、`app/haochen_app/settings/config_store.py`、`app/haochen_app/app_shell.py`（`_external_key_resolves`）。

### 2. Hi 精准跳转（端到端实测通过）
- 深链改为 **`citylink://client/chat/openConversation?type=chat&id=<chatId>`**（**不带 host**）。原因：Hi 主进程 `open-url` 会把 `citylink://` 改写成 `https://citylink.xiaohongshu.com/` 再按 pathname 路由，带 host 会重复导致路由失效、只唤前台不跳对话。
- 单聊/群聊/应用号都用 `type=chat + chatId`（chatId 来自 `hi search:message`）；也支持 `type=account + 邮箱/botAccountId`。
- 关键文件：`app/haochen_app/dashboard/controller.py`（hi 分支）、`adapters/hi.py`。

### 3. hi 探测覆盖修复
- `_find_cli` 改为用**登录 shell 的真实 PATH** 解析 hi（覆盖 npm-global / fnm / volta / asdf / 自定义前缀），`_run` 注入登录 PATH 让 node 可被找到。解决「已装 hi 却显示未找到」。
- 关键文件：`app/haochen_app/dashboard/adapters/hi.py`（`_login_path` / `_find_cli` / `_run`）。

### 4. Hi 模块收敛
- 消息**只保留「@ 我」**（正文含我的名字/薯名或字面 `@`），去掉审批/关键词/机器人等宽匹配。
- **取消「待我处理任务」推送**。
- 已连接但无内容时显示占位「当前没有 @ 你的待处理消息。」。
- 局限（如实）：hi CLI 无「未读」状态、无「私聊/群」类型字段，故「私聊未读」无法可靠识别，本轮落地的是可靠的「@我」。

### 5. 连接卡片交互
- 按钮反映**是否真的连上**（不是是否启用）：未连接时始终显示「开启连接」，点击会重新探测前置条件并尝试完成连接。
- 关键文件：`app/assets/dashboard/dashboard.js`。

### 6. 预装「hi 全家桶」技能 + 全局引导
- 技能随包（`config/skills/hi全家桶/`），起引擎时装到 `<home>/agent/skills/`，pi 自动发现（`PI_CODING_AGENT_DIR=<home>/agent`）。
- 在 pi 工作目录写 `AGENTS.md`：需要检索用户工作类信息时使用 hi 技能 / `hi_lookup`。
- 关键文件：`app/haochen_app/engine_client.py`（`_install_agent_resources`）。

### 7. 日报跳转
- 「今日日报」跳 Cowork；修复 url-only 载荷被误吞的问题。

## 二、构建与分发

- 版本：`VERSION=0.6.2-beta.2`（`scripts/version.py sync` 同步 pyproject / engine；扩展 manifest 0.6.2.2）。
- 打包：`HAOCHEN_BUILD_MODE=legacy bash packaging/build.sh` → `packaging/dist/haochen-0.6.2-beta.2.dmg`。
- Cask：`app/.venv/bin/python scripts/version.py render-cask packaging/dist/haochen-0.6.2-beta.2.dmg --legacy` 生成 `Casks/haochen.rb`（sha256 自动对齐）。
- 门禁：`make check` 全绿（Python 813 passed / 1 opt-in skipped，Node 42/42）。

### Homebrew 内部分发步骤（需所有者执行，含 GitHub 凭据）
1. `gh release create v0.6.2-beta.2 packaging/dist/haochen-0.6.2-beta.2.dmg`（或网页新建 Release，tag=`v0.6.2-beta.2`，资产名不变）。
2. 把 `Casks/haochen.rb` 更新到 tap 的 **main** 分支（brew 只读 main）。
3. 同事安装：`brew install --cask yangwz1993-gif/haochen/haochen`（已装旧版用 `brew upgrade --cask`）。

## 三、首次使用配置（每位用户）
- 内网模型：登录 codewiz-cc + 向导内填邮箱/key。
- Hi 功能：本机装内部 `hi` CLI（`npm i -g @xhs/hi-cli --registry=http://npm.devops.xiaohongshu.com:7001`）+ `hi search:me` 登录。
- 读屏/看图：系统设置授权辅助功能/屏幕录制。

## 四、边界与已知限制
- 自签未公证，仅内部试用；面向公众需 Developer ID + 公证（`release` 模式，本轮未执行）。
- Hi「私聊未读」不可得（hi CLI 无该能力）；「@我」为可靠替代。
- 预装技能的写操作依赖 agent 是否开放 bash；检索类走 `hi_lookup` 最稳。
