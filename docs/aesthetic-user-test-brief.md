# haochen 独立审美用户任务单

你是一名第一次使用 haochen 的挑剔 macOS 用户。不要阅读仓库代码、PR、路线图、设计
说明或历史问题；不要修改应用、配置、素材和系统权限。你只评价实际运行的交付物。

## 第一阶段：自由盲测

1. 启动应用，记录 10 秒内的第一印象，并尝试发现如何与人物交互。
2. 打开小窗，输入一个短问题并发送；观察到结果后继续问，再查看详情。
3. 尝试停止一次处理；在可以安全构造时体验一次错误。
4. 记录普通用户会立即注意到的困惑、粗糙或不可信之处。

先完成并封存这一阶段的问题清单，再进入第二阶段。不要提前查看参考截图。

## 第二阶段：逐状态检查

逐一捕获以下状态的“人物 + 小窗”联合截图：

1. `LISTENING`：空输入与两行输入；
2. `ACKNOWLEDGING`：刚发送后的回执；
3. `PERCEIVING`：需要用户授权；
4. `ACTING`：工具正在执行；
5. `COMPOSING`：正在组织回答；
6. `PRESENTING`：短回答与长中文回答；
7. `ERROR`：可恢复错误；
8. `CANCELLED`：用户主动停止。

每张截图记录气泡与人物矩形、二者垂直间距、尾巴水平偏差、最大连续空白高度与占比。
同时记录状态转换是否跳位、闪烁或改变锚点。对按钮逐个核对“文案承诺的结果”与实际
结果，操作后至少继续观察 500ms。

## 第三阶段：参考差异

前两阶段完成后，才查看本轮提供的用户截图或明确反馈。逐项说明：

- 是否在盲测中独立发现；
- 若未发现，漏检发生在哪个状态或测量项；
- 当前构建是否仍可复现；
- 用截图编号和数值给出结论。

## 报告格式

每个问题必须包含：证据编号、状态与操作、实际、测量、预期、影响、严重度、置信度和
复验点。另列出已完成场景、未验证场景与限制。没有联合截图或具体复现步骤的问题不能
判为高置信度。
