# 一期修复与二期启动条件

本轮来源：2026-09-10 用户验收结论及气泡留白、底色、思考动效补充。用户负责验收，不使用验收 agent。

一期范围：凭据误删/阻塞/验证竞态、权限遮挡和拒绝恢复、展开关闭与当前轮定位、人物可见、目标窗口读屏、气泡布局及中性底色、无文字思考动效、Retina 图标、称谓和简答标记清理。

工程验证后构建 v0.3.4-rc.1，替换本机旧 App 并清理旧安装包；保留用户配置、会话和钥匙串。此候选不直接发布到 Homebrew。等待用户验收通过再进入二期。

二期方案：

- 快捷键唤起并聚焦短输入泡，支持修改、冲突提示、重复收起、草稿恢复、焦点归还；整合已有全局热键，避免重复注册。
- 点击、倾听、思考、回答、展开/收起的连贯动作。
- 全应用字体、颜色、描边、阴影与图标的统一设计。
- 结论先行、信息充分、长度适当的简答与对应详情。
- 完整会话的阅读位置和草稿保持，清晰的复制/停止/重试入口。
- 屏幕边缘、外接屏、缩放及人物避让的完整适配。
- 轻微人物动作，可查看和修改的称呼与偏好记忆。

二期先完成全交互原型，由用户确认视觉和节奏后扩展。暗色模式暂缓。
