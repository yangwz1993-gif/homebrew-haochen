# haochen v0.1.4 问题修复（hotfix）验收点

> 依据：用户真机验证 v0.1.4 后反馈的 4 个问题。给 kimi 实现。属**回归修复 + 部分回退**。

## 1）授权流程：装后未授权就尝试读屏
- **问题**：装了 v0.1.4 后**没授权就直接读了屏**（读到内容了）。怀疑历史 TCC 权限没清 / app 未授权就尝试读屏。
- **要做**：
  - **未授权时不得读屏**：进入 app 若辅助功能/屏幕录制任一未授权，**必须先走授权流程，授权完成后才允许读屏**；未授权期间的 read_screen 应提示未授权、不真正读。
  - **清理历史权限**：干净安装/升级后，确认 TCC 记录与当前签名匹配；若"假蓝"（设置里看似开但未生效），用「重置重授」清旧记录重授权。
  - 首启引导：未授权 → 触发 macOS 系统授权弹窗 + 引导；授权全绿后才进入可读屏状态。

## 2）小窗 UI：灰色底 + 会话框线还在
- **问题**：v0.1.4 改后，小对话窗口消息区**还是灰色底 + 有会话框线**（没改彻底）。
- **要做**：彻底**去掉灰色底**，改**清爽米白卡片化**；**去掉会话框线**（各气泡/输入框不应有深色边框线）。符合 visual-spec（米白 `#fdf6e3` 底、卡片 `#fffaf0`、圆角 16）。

## 3）详情页样式：回退（关键）
- **问题**：v0.1.4 把详情页改得**又小又丑**。用户明确：**回退到之前大而清晰的样式**。
- **要做**：
  - **回退详情页样式**到 v0.1.3 之前那种**大窗口、清晰排版**的样式。
  - **只保留**本次"展开动画效果"（从气泡平滑扩展到详情窗口）。
  - 只做**两处调整**：a）**微调结论位置**（结论在整体回答下的位置，不要变丑/变小）；b）**定位到当前轮**（展开时聚焦当前这一轮对话）。
  - **不要**现在这个小的/丑的详情样式。

## 4）严重 bug：展开后按 Esc 直接退出 app
- **问题**：详情窗口展开后，**按 Esc 直接退出整个 app**（严重！）。
- **要做**：**Esc 只收起会话框/详情窗口**（关闭详情、回到短会话），**绝不能退出 app**。App 只能在用户主动选退出时才退出。
- 回归：确认 ⌘Q / 菜单退出仍正常；Esc 只收起不退出。
