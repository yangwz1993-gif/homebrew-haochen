# Hi 全家桶：文档 / 消息 / 其他操作

hi 内部工作台能力的统一入口，按请求类型路由到子 skill。**先判断请求类型，再进入对应子 skill 读取完整流程与命令。**

## 路由表

| 用户请求 | 路由到 |
|---|---|
| 读/搜/建/编 hi 文档（REDoc） | `hi文档操作/hi-docs` |
| 查文档协作者/编辑记录 | `hi文档操作/查询hidoc协作者` |
| 查 hi 群聊/私聊消息、找人聊天进展，或发送私聊/群聊消息 | `hi消息操作` |
| 看日程/共同空闲/约会议室 | `hi其他操作` |
| 汇总 hi 通知/待跟进/审批提醒 | `hi其他操作` |

## 统一前置检查

每个新轮次先确认环境就绪（只读）：

```bash
which hi
hi search:me
```

- `hi` 未安装：`npm install -g @xhs/hi-cli --registry=http://npm.devops.xiaohongshu.com:7001`
- token 失效：提示用户重新登录/授权，不读取、打印或上传 token 内容
- 所有具体命令先跑 `--help` 核对参数，禁止凭记忆猜测

## 全局边界（所有子 skill 通用）

- 权限 = 当前登录用户的 OAuth 权限，无额外权限。
- **消息写操作受控开放**：允许按 `hi消息操作` 子 skill 的授权、消歧和结果校验规则发送私聊或群聊消息；仍禁止擅自改群设置、拉人或执行未获授权的写操作。日历写操作（建/改/取消日程）必须先展示细节并取得用户明确确认。
- 输出只保留与目标相关的结论/时间/负责人/行动项，避免暴露无关人员敏感信息。
- 不下载、转发或外发聊天附件；不输出 token/cookie/完整附件 URL。
- 搜索命中 ≠ 完整聊天历史/完整私聊列表/真实未读数，表述必须克制。
