# 天梯日报深度集成证据（0.6.2-beta.3 追加）

日期：2026-09-17 凌晨 ｜ 需求：haochen 深度阅读天梯日报+核心事实卡，事实卡自动同步到「我在追踪」并带独立链接

## 交付内容

| 模块 | 实现 |
|------|------|
| **天梯连接器**（adapters/tianti.py） | 只读拉 external/report API；cookie 只从 Keychain 读；邮箱走 hi search:me（不另建账号体系）；misc-「其他」事项不进动态也不同步；风险项目映射 needs_attention；缓存落盘供对话阅读 |
| **Cookie 傻瓜双通道** | ①扩展弹窗「一键连接天梯日报」：点击时才请求 cookies 权限（仅 cowork 域名、仅 web_session），native 桥接回传 → host 落 handoff 文件（0600）→ 主进程收进 Keychain（避免 Chrome 子进程触发 ACL 弹窗）②没装扩展 → 内嵌 WKWebView 登录窗（tianti_auth.py），登录成功瞬间从原生 cookie 仓取 web_session（HttpOnly 可读）自动关窗 |
| **事实卡→追踪全自动同步**（store.sync_tianti_tracks） | active 项目自动建追踪（标题=项目名、目标=项目目标、daily 频率、渠道=事实卡独立链接）；幂等（不重复建）；目标/链接变化会更新；**用户删过的永不复活**（tiantiTombstones）；track_save 编辑保留 tiantiPid 标记 |
| **追踪链接可点** | 追踪事项的渠道列表里 url 渠道带「打开」按钮，直达核心事实卡 |
| **对话深度阅读**（ext read_daily 工具） | 引擎工具读本机缓存的项目卡+进展；问"我日报/某项目进展"时拿真实数据回答 |

## 诚实边界

- cookie 会过期（天梯 SSO 会话时限）→ 失效后连接卡如实提示「一键重连」，不装死
- 事实卡独立链接格式 `…/#daily?project=<pid>` 是按 API 契约拼的，**验收时要跟实际页面对齐一次**（用户说有独立链接）
- 内嵌登录窗要求用户在内网 SSO 登录一次；网页内容不读取，只取 web_session 这一个 cookie
- 扩展的 cookie 权限是 optional + 点击时才请求 + 仅 cowork 域名，默认隐私姿势不变（popup 文案已同步改）

## 验收路径

1. 扩展需在 chrome://extensions 点一次 🔄 重新加载（新增了 optional cookies 权限）
2. 桌面总览 → 连接与外观 → 天梯日报卡 → 「一键连接」→ 按环境分流（有扩展走扩展弹窗/没有走内嵌登录窗）
3. 连接成功 → 应用动态出现项目进展卡；「我在追踪」自动多出各项目的追踪事项
4. 追踪事项详情 → 渠道列表点「打开」→ 跳到核心事实卡
5. 问桌宠「我今天日报怎么样」→ 拿真实数据回答
